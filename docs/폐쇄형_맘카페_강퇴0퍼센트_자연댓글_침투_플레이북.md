## 🚨 1. 왜 일반 홍보는 맘카페에서 1분 만에 강퇴당할까? (4대 감시망)

1. **URL 링크 포함 (`https://`, `.co.kr`)**: 댓글에 주소가 들어가면 카페 금칙어 필터에 걸리거나 즉시 신고당합니다.
2. **상담원/업체 말투 (`~해보세요`, `추천합니다`)**: 실제 엄마들은 댓글에 정식 브랜드 풀네임(`키즈핏 그로스 스튜디오`)이나 딱딱한 안내문을 쓰지 않습니다.
3. **'작성글 보기' 클릭 검증**: 누군가 무언가를 추천하면 엄마들은 습관적으로 닉네임을 눌러 **그 사람이 쓴 이전 댓글/글 목록**을 확인합니다. 가입 후 추천 댓글만 달아놓은 계정은 100% 업자로 간주됩니다.
4. **유료 결제 유도**: 돈을 내야 하는 영양제·교구를 직접 추천하면 경계하지만, **"돈 안 들고 회원가입도 없는 무료 키 백분위·두뇌 계산기"**는 정보 공유로 받아들입니다.

## 🛡️ 2. 폐쇄형 맘카페를 100% 뚫는 【자연 댓글 침투 5대 법칙】

- 절대 링크를 걸지 말고, 풀네임 대신 **"초록창에 키즈핏 무료 성장계산기 쳐서 돌려봤어요"**, **"키즈핏 같은 무료 진단기 돌려보니까 질병관리청 백분위 표로 나오더라구요"**처럼 지나가듯 언급합니다.

- 댓글의 앞부분 80%는 무조건 질문한 엄마의 걱정에 깊이 공감하고 생활 팁을 먼저 줍니다. 마지막 한 줄에만 *"아 그리고 너무 불안하시면..."* 하고 무료 계산기를 덧붙입니다.

### ③ 제3법칙: 【9:1 위장 비율 (일상 댓글 9개 : 정보 댓글 1개)】
- 카페에서 키즈핏 언급 댓글을 1개 달기 전에, 반드시 **"오늘 저녁 반찬 뭐 하세요?", "초1 실내화 어디 거 사세요?", "비 오는데 등교 힘들었네요 ㅠㅠ"** 같은 **순수 일상 댓글 8~9개**를 먼저 달아둡니다. 누군가 내 닉네임을 눌러도 100% 실제 동네 학부모로 보입니다.

  > **본문**: 애가 또래보다 작아서 걱정이라 질병관리청 기준이라는 무료 성장·두뇌 계산기 돌려봤는데, 유전키는 171인데 밤 10시 수면이랑 자세 잡아주면 177까지 된다고 나오네요.. 혹시 이거 해보고 실제로 식단이나 밤 10시 수면 루틴 해보신 분 계신가요?
